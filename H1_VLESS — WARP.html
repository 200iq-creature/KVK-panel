WARP

Cloudflare WARP как выход сервера в интернет: сайты видят адрес Cloudflare, а не IP хостера. Помогает с сервисами, которые блокируют IP дата-центров (ChatGPT, Netflix, Google с капчей), и даёт IPv6. Клиентам ничего настраивать не нужно.

Аккаунт WARP

нет аккаунта
Аккаунта ещё нет. Регистрация бесплатная и занимает пару секунд: панель создаёт ключ WireGuard и регистрирует его в Cloudflare с IP этого сервера (как wgcf).
Ключ WARP+ (необязательно — без него обычный бесплатный WARP)

Режим
Весь интернет-трафик клиентов уходит через WARP. Инбаунды с каскадом и правила «напрямую» из «Инбаундов» по-прежнему работают раньше WARP.
Порт сервера WARP (UDP)
Выход WARP

При «IPv6 сначала» сайты открываются через IPv6-адрес WARP, а без IPv6 — через IPv4. У IPv4- и IPv6-адресов WARP бывает разная страна: включите, если сервис (например, Gemini) определяет страну не так.

Выключен — весь трафик идёт напрямую с сервера

Как это работает

1Сначала — фильтрацияРеклама и опасные сайты отсекаются раньше всего, WARP их не увидит.
2Потом — правила инбаундовКаскад и правила «напрямую» из «Инбаундов» срабатывают раньше WARP.
3Остальное — через WARP или напрямуюПо выбранному режиму: весь трафик, только выбранные сайты или запасной выход.

Важно знать

  • При сохранении xray перезапускается — клиенты переподключатся за 5–8 секунд.
  • Ключ WARP+ необязателен: без него работает обычный бесплатный WARP.
  • «Запасной выход» проверяет прямой выход сервера раз в минуту и включает WARP, только если сайты перестали открываться.
  • Сброс аккаунта удаляет регистрацию в Cloudflare; новый аккаунт можно зарегистрировать снова.
